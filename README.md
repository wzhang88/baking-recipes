# 我的烘焙配方 · Baking Journal

个人烘焙配方与试做记录。当前网站采用单文件 HTML、CSS 和 JavaScript，通过 GitHub Pages 发布。

[打开配方网站](https://wzhang88.github.io/baking-recipes/)

最后更新于 2026-11-19（美国太平洋时间）。

## 当前状态

- 仓库为公开仓库，GitHub Pages 已启用。
- 发布来源为 main 分支根目录，入口文件为 index.html。
- 已上线 27 份配方。
- 已支持按名称与食材搜索、类别筛选、待试做筛选、配方展开和详情锚点链接。
