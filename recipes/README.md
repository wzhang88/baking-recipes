# 双语配方数据格式

一份配方一个 UTF-8 JSON 文件，文件名与现有网页锚点 `id` 相同。先逐份迁移；当前网页仍以 `index.html` 为展示来源，避免部分迁移时显示重复或遗漏的配方。

- `zh`、`en` 是并列的语言内容。翻译未完成时用 `null`，显示端回退中文并明确标示；不得自动编造步骤。
- `amount` 保存原记录的数量字符串；不清楚的单位另用 `detail` 和 `certainty: "unconfirmed"` 说明，不要把推测写成确定用量。
- `category`、`status` 与现有网站筛选值一致；`id` 和 `legacyAnchor` 保持现有 URL 锚点。
- `photos` 预留图片路径、说明和替代文字；`trials` 预留试做日期、调整和心得。公开仓库只收录适合公开的照片和笔记。
- 改版接入这些 JSON 文件时，用内容转义后的 DOM 节点渲染用户文字，避免把笔记作为 HTML 直接插入。

首份示例：`black-sesame-toast.json`。其内容对应网站现有黑芝麻山形吐司；已知不确定项仍保留。迁移其余配方并核对完毕后，再切换网页的数据源与语言按钮。
